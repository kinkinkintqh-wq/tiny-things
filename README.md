# Tiny Things｜小东西制造所

像拼乐高一样，用零件创造可分享、可复用的数字小物件：生活工具、学习辅助、习惯记录、互动礼物与小游戏。信封是其中一种零件和组合玩法。

## 下载源码与复现

[完整源码包：214个文件](tiny-things-source-20261113.zip) 保留目录结构、依赖锁文件、测试、网表与证据。包内SOURCE-SHA256.json可逐文件校验；不是仅有界面图片。

解压后在项目根目录运行：

~~~sh
npm --prefix apps/web ci
npm --prefix packages/tapeout-adapter ci --ignore-scripts
npm test
npm run dev
~~~

Node.js 22+；打开 http://127.0.0.1:3846 。无需数据库即可运行本机制作、预览、导入导出和快照试玩。

源码包SHA256：e2723a3195ba3a535ceef27e6ae2c76bbb55f5f20dbba3d2ebf01b7f8c685e86 。[包信息](SOURCE-PACKAGE.json)。
